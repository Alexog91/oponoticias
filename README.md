# OpoNoticias 📋

**Las convocatorias de oposiciones del BOE, contadas en lenguaje claro.**

OpoNoticias es una plataforma web que automatiza la lectura diaria del Boletín Oficial del Estado (BOE) español, extrae convocatorias de oposiciones, genera resúmenes inteligentes con IA, y las publica de forma clara y accesible.

🌐 **Web:** [oponoticias.com](https://oponoticias.com)  
📱 **Telegram:** [@OPONOTICIAS](https://t.me/OPONOTICIAS) (280+ suscriptores)  
📊 **Base de datos:** 194+ convocatorias indexadas

---

## ✨ Features

- ✅ **Lectura automática del BOE** cada día a las 9:30 CEST
- ✅ **Resúmenes con IA** (Claude API) - extrae datos específicos sin términos genéricos
- ✅ **Publicación en Telegram** con formato limpio y profesional
- ✅ **Almacenamiento en Supabase** - base de datos relacional
- ✅ **Generación automática de HTML** - una página por convocatoria
- ✅ **Despliegue en Vercel** - redeploy automático en cada push
- ✅ **SEO optimizado** - meta tags, schema.org, Open Graph
- ✅ **Diseño magazine editorial** - paleta neutral cálida, tipografía profesional
- ✅ **Responsive** - funciona en móvil, tablet y desktop
- ✅ **Sin dependencias pesadas** - HTML/CSS/JS vanilla

## 🏗️ Tech Stack

### **Backend & Automation**
- **Python 3.11** - Script de lectura del BOE
- **GitHub Actions** - Ejecución automática diaria (cron)
- **Anthropic Claude API** - Generación de resúmenes inteligentes

### **Frontend**
- **HTML5 + CSS3 + Vanilla JavaScript**
- **Tipografía:** Merriweather (display) + Inter (body)
- **Animaciones:** CSS @keyframes + IntersectionObserver
- **Sin frameworks:** Puro HTML estático

### **Base de datos & Almacenamiento**
- **Supabase** - Base de datos PostgreSQL
- **GitHub** - Control de versiones + almacenamiento de HTML

### **Deployment**
- **Vercel** - Hosting estático + auto-deploy
- **Vercel CLI** - Configuración de dominios

### **Integración**
- **Telegram Bot API** - Publicación de alertas
- **BOE RSS Feed** - Lectura automática `https://www.boe.es/rss/boe.php?s=2B`

## 🚀 Cómo Funciona

### **Flujo Automático (cada día a 9:30 CEST)**

```
1. GitHub Actions ejecuta leer_boe.py
   ↓
2. Lee RSS del BOE (convocatorias de oposiciones)
   ↓
3. Para cada convocatoria:
   ├─ Envía a Claude API para generar resumen
   ├─ Guarda en Supabase (detecta duplicados con UNIQUE)
   ├─ Si es nueva:
   │  ├─ Publica en Telegram @OPONOTICIAS
   │  ├─ Genera HTML /convocatoria/[slug].html
   │  └─ Hace commit y push a GitHub
   ↓
4. Regenera sitemap.xml
   ↓
5. Vercel detecta push y redeploya automáticamente
   ↓
6. oponoticias.com se actualiza con nuevas páginas
```

### **Variables de Entorno (GitHub Secrets)**

Para que el workflow funcione, configurar 6 secretos en GitHub:

```
TELEGRAM_TOKEN           # Token del bot de Telegram (@BotFather)
TELEGRAM_CHAT_ID         # ID del canal @OPONOTICIAS
SUPABASE_URL            # URL del proyecto Supabase
SUPABASE_API_KEY        # Anon key de Supabase
ANTHROPIC_API_KEY       # API key de Claude
GITHUB_TOKEN            # Personal Access Token de GitHub
```

## 📋 Schema de Base de Datos (Supabase)

Tabla `convocatorias`:

```sql
CREATE TABLE convocatorias (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  fecha TEXT NOT NULL,
  titulo TEXT NOT NULL UNIQUE,
  enlace TEXT NOT NULL,
  resumen TEXT,
  cuerpo TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_titulo ON convocatorias(titulo);
CREATE INDEX idx_fecha ON convocatorias(fecha DESC);
```

## 🔧 Instalación Local

### **Requisitos**
- Python 3.11+
- Git
- Variables de entorno configuradas (ver `.env.example`)

### **Setup**

```bash
# 1. Clonar repositorio
git clone https://github.com/Alexog91/oponoticias.git
cd oponoticias

# 2. Configurar variables de entorno
export TELEGRAM_TOKEN="your_token"
export SUPABASE_URL="your_url"
# ... (ver todas en DEPLOYMENT.md)

# 3. Ejecutar script manualmente (opcional)
python3 leer_boe.py
```

**Resultado:**
- Lee RSS del BOE
- Genera HTML en `/convocatoria/`
- Publica en Telegram (si hay nuevas)
- Guarda en Supabase
- Hace commit a GitHub
